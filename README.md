# Undangan Hizul & Tania — versi GitHub Pages

## Isi folder
- index.html      : halaman undangan (jangan diedit manual)
- checkin.html    : halaman petugas scan QR
- config.js       : SEMUA pengaturan (tanggal, rekening, foto, musik, URL Apps Script)
- js/             : api.js, isi.js, checkin.js (jangan diubah)
- assets/foto/    : foto mempelai & galeri
- assets/musik/   : musik latar
- assets/logo/    : logo pengantin
- assets/latar/   : latar watercolor & bunga

## Ganti foto / musik
Unggah file dengan NAMA YANG SAMA ke folder yang sesuai (GitHub: buka folder > Add file > Upload files > Commit).
- Foto mempelai : assets/foto/hizul.jpg , assets/foto/tania.jpg
- Galeri        : assets/foto/galeri-1.jpg ... galeri-6.jpg
- Musik         : assets/musik/musik.mp3
Ingin nama/jumlah lain? Ubah daftarnya di config.js.
